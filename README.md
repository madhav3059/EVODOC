# EVODOC
Evodoc nursing and doctor 
Project Overview
This project is a functional prototype of a coordinated healthcare platform built for EvoDoc. It consists of two primary portals designed to make quality care more accessible and coordinated:
1. Nurse & Receptionist Portal: Focused on high-efficiency patient intake and appointment scheduling.
2.Doctor Portal: Designed for schedule management and clinical activity.
Core Features1. Nurse & Receptionist PortalMulti-Section Intake Form: Groups related fields (Personal, Medical, Emergency) to improve data entry flow and clarity.Field Validation: Implements required checks for critical data like Full Name and DOB to ensure data integrity.Appointment Registration: Features a doctor selection tool with availability indicators to prevent scheduling conflicts.Scannable List View: A searchable and filterable table allowing staff to quickly view, edit, or cancel appointments.2. Doctor PortalOverview Dashboard: Provides a "full picture at a glance" including total appointments and recent activity.Appointments View: Cards with patient details and clear status indicators (Scheduled/Completed).Patient Details Page: A dedicated clinical view for medical history and a field to add new clinical notes.
